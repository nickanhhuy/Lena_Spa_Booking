# 🌸 Lena Beauty Spa

**Lena Beauty Spa** is a web application for easy spa appointment booking and management.

---

## Main Features

- **Role-based Access:** Admins manage services, bookings, and announcements. Users book appointments.
- **Smart Time Slot Checker:** Instantly checks and prevents double bookings.
- **Email Announcements:** Important updates sent directly to users' inboxes.

---

## Tech Stack

- **Frontend:** Angular
- **Backend:** Spring Boot

---

Lena Beauty Spa makes spa scheduling simple and smart.
